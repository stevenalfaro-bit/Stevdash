# Stevdash

A browser-based endless runner inspired by a popular rhythm-dash style game, rebuilt as a simple HTML canvas game.

## How to run

Open `index.html` in a browser, or serve the folder with a local web server.

Example:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000

## Controls

- Space / Up / W: jump
- Click: jump
